# Tamil Bible Compare+ for macOS

An offline, multi-translation Tamil and English Bible reader for Mac.

Read 21 Tamil and English translations side by side, search across them, and
keep your bookmarks, highlights and notes — all without an internet
connection. Nothing is uploaded, and no account is needed.

## Download

Get the latest build from the
[Releases page](../../releases/latest):

- **`TamilBibleComparePlus-macOS.dmg`** — open it and drag the app to Applications.

[Direct link to the newest build](../../releases/latest/download/TamilBibleComparePlus-macOS.dmg)

Universal build: one download runs natively on both Apple Silicon (M1–M4) and
Intel Macs.

### First time you open it

macOS will refuse to open the app on the first launch and say it "cannot be
opened because Apple cannot check it for malicious software". This is
Gatekeeper reacting to an app downloaded from outside the App Store — it is
not a warning about this app specifically.

To open it the first time:

1. Drag **Tamil Bible Compare+** to your **Applications** folder.
2. Try to open it once, and let the warning appear.
3. Open **System Settings → Privacy & Security**, scroll to the bottom, and
   click **Open Anyway** next to the message about Tamil Bible Compare+.
4. Confirm with **Open**.

You only need to do this once. Every later launch opens normally.

> On macOS 14 and earlier you can instead Control-click the app and choose
> **Open**. Apple removed that shortcut in macOS 15, so on newer systems use
> the Privacy & Security route above.

## Features

- **21 bundled translations** — 7 Tamil and 14 English, all included in the
  download
- **Fully offline** — every translation is stored in the app
- **Side-by-side comparison** — switch on several translations and each verse
  is shown in all of them, one under the other
- **Search** across the translations you have enabled
- **Bookmarks with colour labels** you define yourself
- **Verse highlights** and **personal notes**
- **Cross references** for the verse you are reading
- **5 reading plans** with a calendar and day-by-day progress
- **Progress tracking** — chapters read, days read, current streak, and
  achievement badges
- **Verse of the day** on the home page
- **Read aloud** — hears the chapter verse by verse in Tamil or English, with
  the highlight following the audio
- **Guided tours** that walk you through the reader, settings, bookmarks and
  plans
- **Fonts and themes** — separate typefaces for Tamil and English, light/dark
  mode, accent colour, and three light reading styles including Soft Sepia
- **Export** a chapter as PDF or plain text
- **Backup and restore** everything to a single file
- **Keyboard navigation** throughout

## Read aloud and speech voices

Read Aloud uses the speech voices installed in macOS — the app does not ship
its own. English works out of the box on every Mac. **Tamil needs a Tamil
voice to be downloaded first**, which macOS does not include by default:

**System Settings → Accessibility → Spoken Content → System Voice →
Manage Voices**, then find Tamil and download the voice.

The app detects a missing voice before it tries to speak and opens a
step-by-step guide rather than playing silence. You can reach the same guide
any time from **Help → Set up a Tamil voice**.

## Keyboard shortcuts

| Keys | Action |
|---|---|
| `→` / `←` | Next / previous chapter |
| `⌘→` / `⌘←` | Next / previous chapter, starting at verse 1 |
| `↑` / `↓` | Previous / next verse |
| `⌘↑` / `⌘↓` | Previous / next book |
| `1`–`9`, `0` | Jump to chapter 1–10 |
| `⌘F` | Search |
| `⌘1`–`⌘4` | Home, Read, Search, Settings |
| `⌘+` / `⌘−` | Larger / smaller text |
| `⌘⇧C` | Copy verse with reference |

The full list is in the app under **Help → Keyboard Shortcuts**.
