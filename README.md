## Download

Open the [Releases](../../releases/latest) page and download:

- `TamilBibleComparePlus-macOS-vX.X.X.zip`

The universal application supports both Apple Silicon and Intel Macs.

## System requirements

- A supported version of macOS
- Apple Silicon or Intel processor
- Approximately 150 MB of available disk space

## First launch

The application is currently distributed outside the Mac App Store and may
not be notarized.

If macOS prevents the first launch:

1. Move **Tamil Bible Compare+** to the Applications folder.
2. Control-click or right-click the application.
3. Select **Open**.
4. Confirm by selecting **Open** again.

Only download the application from this official repository or the official
ChristLyrics website.
